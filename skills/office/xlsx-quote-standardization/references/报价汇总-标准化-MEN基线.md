# 报价汇总标准化 - 项目基线文档

本文档是报价汇总标准化项目的概念基线（Concept Baseline），回答 WHY + WHAT。

**两份基线文档的分工**：
- **本文档（项目基线）**：WHY + WHAT - 项目目标、架构、决策理由
- **MIGRATION_RULES.md（规则手册）**：HOW - 函数签名、编码规范、生成规则

---

## 0. 项目目标

**核心问题**：源文件包含 21 个客户 sheet，每个 sheet 格式不统一（排版、列名、公式语义、合并方式各异），无法做跨客户分析。

**项目目标**：建立标准化模板，把所有客户 sheet 迁移到统一格式，使下游能：
- 跨客户横向比较（同一物料号在不同客户的报价/利润率）
- 财务分析自动化（损益率、系列盈亏、总盈亏）
- 错误检测（公式异常、合并错位、丢值）

**成功标准**：
- 24 列 schema 完整
- 7 个派生公式列 100% 公式化（O/R/S/T/U/V/W）
- 货币格式 16 列 100% 应用
- A/V/W 合并单元格与原表布局一致
- 公式可被 Excel 实时重算
- 单 sheet 多数据块 + 子块分割支持

## 1. 架构（M.E.N. 三大支柱）

### 1.1 M - Metadata（元数据 / 世界观）

三层模板-实例架构：

```
L1 哲学层（333 sheet）→ L2 区域母模板（埃及机型报价模板）→ L3 客户实例（IBC/白鲸/...）
```

**关键洞察**：
- 333 是定价哲学（"对外/对内/客户三问"），不绑具体列
- 埃及机型报价模板是埃及市场标准，所有埃及客户从它衍生
- 其他客户实例各自独立，遵循 333 哲学

**多数据块铁律**：
- 一个客户 sheet 可含多个数据块（不同日期/不同型号组合的报价快照）
- 所有块合并到同一个输出 sheet（不拆 sheet）
- 块间空 3 行分隔
- **子块**：同一标题下 C 列为空的行分割子块，W 各自独立

### 1.2 E - Essence（第一性原理 / 铁律）

| # | 铁律 | 含义 |
|---|------|------|
| E1 | 物料号是主键 | C 列 = 正则 `^Z[0-9A-Z]{8,}$` |
| E2 | 24 列 schema 不可变 | 跨客户横向比较的基础 |
| E3 | 净价必为公式 | 销售落地价，禁硬编码 |
| E4 | 标题行承载宏观变量 | `客户名 铜价/汇率` 格式 |
| E5 | 历史字段独立保留 | 时间线分析 |
| E6 | 财务公式必含 | 结算价/净收入/毛利/损益率必为公式 |
| E7 | 系列盈亏 + 总盈亏聚合 | 财务分析能力 |
| E8 | 排版与原始对齐 | 标题/表头/数据布局一致 |
| P0 | 公式总是写入 + IFERROR | 源数据缺值时公式返回 0 |

### 1.3 N - Non-linear（路径弹性）

| 弹性维度 | 策略 |
|----------|------|
| 扩展客户 | 加 COL_MAP + 几行调用 |
| 跳过某块 | 显式指定源行范围 |
| 块间距 | 在 write_data_rows 调用间留空行 |
| 公式列扩展 | 在 write_data_rows 的 24 列分支中加 |
| 数据修正 | P0 修复后：改源数据即可重算所有派生列 |

## 2. 关键决策与理由

| 决策 | 选择 | 理由 |
|------|------|------|
| 主键字段 | **C（订单明细）** | 跨客户唯一标识 |
| 字段数 | **24** | 含 5 个财务分析列 |
| 货币格式 | `\$#,##0.00_);[Red]\(\$#,##0.00\)` | 与原表一致；负数红字括号 |
| 净价公式 | `=IFERROR(J-K-L-M-N,0)` | 源缺值时返回 0 而非断裂 |
| 块间分隔 | **3 行** | 视觉清晰 |
| 多块同 sheet | **是** | 不要把同一客户的不同块拆 sheet |
| V 公式 | **比率** `SUM(T)/SUM(S)` | 财务语义"盈亏率" |
| W 公式锚点 | **子块首数据行** | Excel 合并单元格约束 |
| 枚举映射 | **保留原值** | 避免丢失原始语义 |
| 公式条件 | **总是写 + IFERROR** | 源缺值时公式列不断裂 |

## 4. 24 列 Schema

| # | 列 | 字段 | 类型 | 公式 |
|---|-----|------|------|------|
| 1-6 | A-F | 类别/产品类别/订单明细/工厂型号/配置描述/压缩机 | 文本 | — |
| 7 | G | 数量 | 数字 | — |
| 8-9 | H-I | 历史报价/客户目标价 | 数字 | — |
| 10 | J | 报价 | 数字(蓝字黄底) | — |
| 11-14 | K-N | 财务/OA/返点/其他 | 数字 | — |
| 15 | O | 净价 | **公式** | `=IFERROR(J-K-L-M-N,0)` |
| 16-17 | P-Q | 原型机成本/铜管成本 | 数字 | — |
| 18 | R | 结算价 | **公式** | `=IFERROR(P+Q,0)` |
| 19 | S | 净收入 | **公式** | `=IFERROR(J*G,0)` |
| 20 | T | 毛利 | **公式** | `=IFERROR((J-R)*G,0)` |
| 21 | U | 单机型损益率 | **公式** | `=IFERROR(IF(S=0,0,T/S),0)` |
| 22 | V | 系列盈亏 | **公式** | `=SUM(T系列)/SUM(S系列)` |
| 23 | W | 总盈亏 | **公式** | `=SUM(T子块)/SUM(S子块)` |
| 24 | X | 铜管规格 | 文本/数字 | — |

## 5. 术语表

| 术语 | 含义 |
|------|------|
| Schema | 24 列字段定义 |
| 物料号 | 工厂内部物料编码（C列） |
| 净价 | 销售落地价 = 报价 - 财务 - OA - 返点 - 其他 |
| 结算价 | 成本结算价 = 原型机成本 + 铜管成本 |
| 净收入 | 销售总收入 = 报价 × 数量 |
| 毛利 | 利润绝对值 = (报价 - 结算价) × 数量 |
| 单机型损益率 | 利润率 = 毛利 / 净收入 |
| 系列盈亏 | 每产品系列总盈亏率（V列） |
| 总盈亏 | 每子块总盈亏率（W列） |
| IFERROR 防护 | 公式包 IFERROR(..., 0) 避免 #DIV/0! |
| 子块 | 同一标题下被空行分割的独立数据段 |
| MVS | Minimum Viable State |

## 6. 已知限制

| 限制 | 缓解 |
|------|------|
| Excel 公式不跨块计算 | 业务上正确（不同日期快照） |
| 源 P 列含文本 | 标 PENDING 待裁决 |
| 部分客户无报价 J 列 | IFERROR 返回 0 |
| 公式重算需 LibreOffice | 公式逻辑简单，可手动验证 |
